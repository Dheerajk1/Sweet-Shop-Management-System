# 🍬 Sweet Shop Management System

A full-stack **Sweet Shop Management System** built using **Spring Boot (Java)** for the backend and **React.js** for the frontend.  
The application allows users to **add, view, and delete sweets** through a clean UI backed by RESTful APIs.

## 🚀 Features

### Backend (Java – Spring Boot)
- RESTful CRUD APIs for sweets
- Spring Data JPA with PostgreSQL
- Layered architecture (Controller, Service, Repository)
- Basic Authentication using Spring Security
- Clean and maintainable code structure
